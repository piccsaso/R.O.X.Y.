# Dependency attribution for Sol's source manifest

These are software dependencies, not mission observations. Exact resolved versions
are recorded in `package-lock.json`; each package retains its upstream licence.

| Package | Use | Licence | Source |
|---|---|---|---|
| Three.js | WebGL viewer | MIT | https://github.com/mrdoob/three.js |
| Ajv | JSON Schema validation | MIT | https://github.com/ajv-validator/ajv |
| Vite | Local server and bundler | MIT | https://github.com/vitejs/vite |
| TypeScript | Static checking | Apache-2.0 | https://github.com/microsoft/TypeScript |
| Vitest | Unit tests | MIT | https://github.com/vitest-dev/vitest |
| glTF Transform | GLB generation and reading | MIT | https://github.com/donmccurdy/glTF-Transform |
| pngjs | Synthetic exposure PNG | MIT | https://github.com/pngjs/pngjs |
| tsx | Cross-platform TypeScript CLI | MIT | https://github.com/privatenumber/tsx |
| Playwright | Browser acceptance checks | Apache-2.0 | https://github.com/microsoft/playwright |
| DefinitelyTyped | Type declarations | MIT | https://github.com/DefinitelyTyped/DefinitelyTyped |

All generated test-scene meshes and exposure imagery are original synthetic CC0
fixtures. No NASA imagery, measured radiation or real landmark positions are used.
